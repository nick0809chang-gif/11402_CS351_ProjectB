# 📊 CSV Mini Database & Query Engine

## 📌 Overview
This project implements a lightweight **CSV-based mini database system** with a custom **query engine**. It allows users to perform database-like operations on CSV files without relying on traditional DBMS (e.g., MySQL, PostgreSQL).

The system treats CSV files as structured tables and supports simplified SQL-like queries for data retrieval and manipulation.

---

## 🚀 Features
- 📂 Load CSV files as tables  
- 🔍 Query data using SQL-like syntax  
- 📑 Column selection (`SELECT`)  
- 🎯 Conditional filtering (`WHERE`)  
- 🔃 Sorting (`ORDER BY`)  
- 📊 Basic aggregation (`COUNT`, `SUM`, etc.) *(optional)*  
- 🔗 Table joining (`JOIN`) *(optional)*  
- ⚠️ Error handling for invalid queries and malformed CSV files
